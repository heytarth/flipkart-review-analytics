## The criterion

> **`human_label = 1`** if the review is **low-information**: it contains no product-specific or
> experience-specific detail. A reader could not tell what was bought or what happened to the
> buyer from the text alone.
>
> **`human_label = 0`** otherwise: the review names a feature, a use case, a problem, a
> comparison, a delivery or service experience, or any other concrete detail.

### What this is NOT

This does **not** label reviews as fake, paid or fraudulent. Authenticity cannot be determined
from review text alone, and this dataset has no ground truth for it. You are measuring
**information content only**. Say exactly this in the report.

## Worked examples

| Review | Label | Reason |
|---|---|---|
| `Good` | 1 | No detail whatsoever |
| `Awesome product` | 1 | Generic praise, no specifics |
| `Love it` | 1 | Sentiment only |
| `Average` | 1 | Verdict with no content |
| `So cute` | 1 | Generic, applies to any product |
| `Nice camera and good picture quality` | 0 | Names features (camera, picture quality) |
| `Good har product par dalivery charge` | 0 | Raises a delivery-charge issue |
| `Best DTH but not connect with mobile` | 0 | Specific compatibility problem |
| `Perfect to fit` | 0 | Refers to fit — a concrete property |
| `Value for money very nice product` | 0 | Borderline, but makes a price-value claim |

## Borderline rules — decide once, apply consistently

1. **Length is not the criterion.** A long review of repeated generic praise is still `1`. A
   three-word review naming a feature is `0`.
2. **Misspellings don't matter.** `Suparb` is treated as `Superb` → `1`.
3. **A bare rating restatement** (`Ratting 10/10`) → `1`.
4. **Any named attribute** (size, sound, battery, colour, delivery, installation, price) → `0`.
5. If genuinely undecidable after 5 seconds, label `0`. This biases *against* the flag, so the
   reported precision becomes a conservative lower bound — which is the safer direction to err.

## Strongly recommended: a human labeller

Because the existing labels are LLM-generated, a human pass is what would let the project
claim human validation at all. Label the same rows independently (50 is enough for a
spot-check; 200 replaces the LLM labels outright), then report agreement:

```python
from sklearn.metrics import cohen_kappa_score
print(cohen_kappa_score(labels_you, labels_them))
```

Kappa above 0.6 is substantial agreement, above 0.8 is near-perfect. Reporting human-vs-LLM
agreement turns the provenance weakness into a measured quantity, which is a stronger methods
story than either leaving it undisclosed or dropping the validation.

# Criterion refinement applied during labelling (disclosed)

Recorded after the 200 rows were labelled on 2026-10-07. Disclosed here because the criterion
above was fixed in advance, and any deviation from it must be stated rather than absorbed
silently.

**Refinement:** *naming the product category counts as informative.*

| Review | Label given | Reasoning |
|---|---|---|
| `Nice product` | 1 | "product" is generic — tells the reader nothing |
| `Nice phon` | 0 | names what was bought |
| `Nice watch.... Must buy...` | 0 | names what was bought |
| `Very nice cycle thanks flipkart` | 0 | names what was bought |
| `A very good juicer` | 0 | names what was bought |

This is consistent with the headline criterion ("could a reader tell *what was bought*"), but it
is more specific than the examples originally listed, so it is recorded as a refinement rather
than presented as part of the original rule.

**Softest boundary in the labelled set:** bare verdicts were treated as generic while explicit
price-value claims were treated as informative — `Worth it` → 1 and `Value for` → 1, but
`worth for money` → 0 and `Value for money very nice product` → 0. This distinction is defensible
but thin, and is the most likely point of disagreement with a second labeller.

**Final label distribution:** 133 low-information (66.5%), 67 informative (33.5%), n = 200.

**One labeller only, and it was an LLM.** Inter-rater agreement (Cohen's kappa) was not
measured, so the criterion's reproducibility is untested — and no human has checked any of the
200 labels. State this as a limitation.
